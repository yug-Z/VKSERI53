# Mahindra Thar Craft Run

A lightweight browser game inspired by Minecraft-style block visuals where you drive a Mahindra Thar across a voxel-like desert.

## Features

- Minecraft-inspired block terrain rendering on HTML canvas.
- Playable Thar driving controls (W/A/S/D and Arrow keys).
- Real-time HUD for speed and distance.
- Player sentiment capture with mood + free-text feedback.
- Auto sentiment capture every 10 seconds.
- Local sentiment history persistence with trend chart using `localStorage`.

## Run locally

```bash
python3 -m http.server 4173
```

Then open: `http://localhost:4173`
